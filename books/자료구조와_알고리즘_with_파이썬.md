### 자료구조와 알고리즘 개요

### 자료구조의 이해

#### 자료구조에 관한 오해

#### 자료구조의 정의

자료구조는 한정된 메모리에서 처리에 필요한 데이터에 효율적으로 접근하기 위한 자료의 조직, 관리, 저장 방법이다.

#### 자료구조의 필요성

- 메모리 효율성
- 알고리즘 성능
- 데이터 관리

### 알고리즘의 이해

#### 알고리즘의 정의

알고리즘은 문제 해결을 순서 대로 정의한 것이며, 순서대로만 따라하면 문제가 해결되는 것을 말한다.

#### 컴퓨터 알고리즘

컴퓨터 알고리즘의 요건

- 0개 이상의 입력
- 1개 이상의 출력
- 정확성
- 유한성
- 수행성

### 자료구조와 알고리즘

알고리즘을 컴퓨터로 수행하고자 할 때 데이터를 메모리에 저장해야 하며 이 때 자료구조가 필요하다. 자구조를 이용해서 데이터를 메모리에 저장할 때 특정 규칙을 포함해 저장할 수 있는데, 이러한 규칙을 알고리즘이라고 부른다.

## 2장 데이터 표현

### 정보와 데이터

컴퓨터로 문제를 해결한다는 것은 컴퓨터 알고리즘이 만들어졌다는 것이며, 컴퓨터 알고리즘은 특정 입력값에 대해 처리 과정을 거쳐 원하는 답을 출력한다는 것이다.

문제 해결 목적에 맞게 정리된 저자료를 정보라고 정의할 수 있다. 이한 정보가 컴퓨터 저장 방식에 맞추어 변환된 자료를 데이터라고 정의할 수 있다.

### 컴퓨터 기억장치

#### 주기억장치

- 주기억장치
    - 메인메모리(Main Memory), RAM(Random Access Memory)이라고 하며 컴퓨터에서 처리되는 데이터가 저장되는 기억장치
    - 휘발성 기억 장치라고도 하며, 데이터를 영구적으로 보관하지 못하는 특징을 가진다.
- 보조기억장치
    - 하드디스크(HDD, SDD)나 USB
    - 비휘발성 기억장치라고 하며, 파일이나 프록램, 정보를 지속해서 보관할 수 있는 기억장치

#### 래치 회로

래치(LATCH) 회로는 두 개의 전기회로를 회전하도록 연결하여 만든 메모리 기억장치 회로로, 두 개의 NAND 회로나 NOR 회로로 구성된다.
