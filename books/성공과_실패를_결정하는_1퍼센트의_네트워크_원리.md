1. URL입력부터 시작한다.
2. 브라우저는 먼저 URL을 해독한다.
3. HTTP 리퀘스트 메시지를 만든다.

| Term & Category | Definition, Role & Example |
| :--- | :--- |
| **URL** | Uniform Resource Locator |
| **FTP(File Transfer Protocol)** | 파일을 업로드하거나 다운로드할 때 사용하는 프로토콜. FTP 프로토콜을 이용하여 파일 전송을 하는 프로그램도 'FTP'라고 한다. |
| **도메인명** | `www.cyber.co.kr`과 같이 마침표로 구분하여 표현하는 이름 |
| **포트 번호** | 액세스 대상 서버 애플리케이션을 지정하여 사용하는 번호 (e.g., 웹이라면 `80`번, 메일이라면 `25`번) |
| **HTTP** | HyperText Transfer Protocol |
| **프로토콜** | 통신 동작의 규칙을 정한 것 |
| **디렉토리** | 디렉토리는 윈도우에서 '폴더'와 같은 의미의 용어 |
| **URI** | Uniform Resource Identifier |
| **CGI 프로그램** | 웹 서버 소프트웨어에서 프로그램을 호출할 때의 규칙을 정한 것. CGI의 규칙에 맞게 움직이는 프로그램을 'CGI 프로그램'이라고 한다. |
| **폼** | 웹 페이지에 있는 텍스트 입력 상자나 체크박스 등이 표시된 부분 |
