## <a id="ch07"></a>📚 핵심 용어 사전

| Term & Category | Definition, Role & Example |
| :--- | :--- |
| **URL** | Uniform Resource Locator |
| **FTP(File Transfer Protocol)** | 파일을 업로드하거나 다운로드할 때 사용하는 프로토콜. FTP 프로토콜을 이용하여 파일 전송을 하는 프로그램도 'FTP'라고 한다. |
| **도메인명** | `www.cyber.co.kr`과 같이 마침표로 구분하여 표현하는 이름 |
| **포트 번호** | 액세스 대상 서버 애플리케이션을 지정하여 사용하는 번호 (e.g., 웹이라면 `80`번, 메일이라면 `25`번) |
| **HTTP** | HyperText Transfer Protocol |
| **프로토콜** | 통신 동작의 규칙을 정한 것 |
| **디렉토리** | 디렉토리는 윈도우에서 '폴더'와 같은 의미의 용어 |
| **URI** | Uniform Resource Identifier |
| **CGI 프로그램** | 웹 서버 소프트웨어에서 프로그램을 호출할 때의 규칙을 정한 것. CGI의 규칙에 맞게 움직이는 프로그램을 'CGI 프로그램'이라고 한다. |
| **폼** | 웹 페이지에 있는 텍스트 입력 상자나 체크박스 등이 표시된 부분 |
| **태그** | 웹 페이지를 쓸 때 이용하는HTML이라는 문법에서 결정된 제어 정보. 예를 들어 문장 안에 영상을 포함한 경우에는 ```<img src="image.jpg">```라는 형태의 태그를 문장에 포함시킨다. |
| **라우터** | 패킷을 중계하는 장치의 일종 |
| **허브** | 패킷을 중계하는 장치의 일종이며, 리피터 허브와 스위칭 허브의 두 가지 유형이 있다. |
| **DNS(Domain Name System)** | 서버명과 IP주소를 대응시키기 위해 DNS를 가장 많이 사용하지만, DNS의 기능은 다양하다. 메일 주소와 메일 서버를 대응시키는 것 등 다양한 정보를 이름에 대응해서 등록할 수 있다. |
| **리졸버(resolver)** | DNS 서버에 조회한다는 것은 DNS서버에 조회 메시지를 보내고, 거기에서 반송되는 응답 메시지를 받는 것이다. 이것은 DNS 서버에 대해 클라이언트로 동작한다고도 말할 수 있다. 이 DNS클라이언트에 해당하는 것을 DNS리졸버 또는 리졸버라고 한다. DNS의 원리를 사용하여 IP 주소를 조사하는 것을 네임 리졸루션(name resolution, 이름 확인)이라고 하는데, 이 리졸루션을 실행하는 것이 리졸버이다. <br>리졸버의 실체는 Socket 라이브러리에 들어있는 부품화한 프로그램이다. |
| **프로토콜 스택** | OS 내부에 내장된 네트워크 제어용 소프트웨어. '프로토콜 드라이버', 'TCP/IP 소프트웨어' 등으로도 부른다. |
| **MX(Mail eXchange)** | 클라이언트에서 DNS서버로 보낸 조회메시지에 포함된 타입은 IP주소를 조회할 때는 A를 사용하지만, 메일 배송 목적지를 조회할 때는 MX를 사용한다.  |
| **캐시** | 한 번 사용한 데이터를 데이터의 이용 장소와 가까운 곳에 있는 고속의 기억 장치에 저장하여 두 번째 이후의 이용을 고속화하는 기술을 말한다. CPU와 메모리 사이에 두는 캐시 메모리나 디스크 장치의 데이터를 메모리에 캐시하는 방법 등을 이전부터 사용했는데, 네트워크에서도 캐시 기술에 의해 고속화하는 방법이 일반화되어 있다. |
